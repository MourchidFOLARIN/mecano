# 📚 Documentation API Mékano V1 (34 Endpoints)

Ce dossier autonome contient la documentation interactive complète de l'API REST de **Mékano** (Catalogue véhicules, Atelier mécanique, Blog technique, Médias Cloudinary IA, Tableau de bord métriques).

---

## 💻 1. Utilisation Immédiate en local
Double-clique simplement sur le fichier **`index.html`** présent dans ce dossier !
Il s'ouvrira instantanément dans ton navigateur (Chrome, Edge, Firefox, Brave) sans nécessiter de serveur web ou de commande terminal.

---

## ☁️ 2. Hébergement Gratuit en 30 secondes

Tu peux héberger ce dossier seul sur n'importe quel service statique :

- **Vercel Drop** :
  1. Ouvre ton terminal dans ce dossier et tape `npx vercel` (ou dépose-le sur [vercel.com/new](https://vercel.com/new)).
  2. Tu auras une URL publique en HTTPS : `https://mekano-api-docs.vercel.app`.

- **Netlify Drop (Sans ligne de commande)** :
  1. Ouvre [app.netlify.com/drop](https://app.netlify.com/drop).
  2. Glisse-dépose ce dossier `mekano-api-docs`.
  3. Le site est en ligne immédiatement.

- **GitHub Pages** :
  1. Pousse ce dossier sur un dépôt GitHub.
  2. Active GitHub Pages dans *Settings ➔ Pages*.

---

## 🛠️ 3. Import dans Postman / Insomnia
Le fichier **`openapi.yaml`** est la spécification OpenAPI 3.0.3 officielle. Tu peux l'importer directement dans Postman ou Insomnia (*Import ➔ openapi.yaml*) pour avoir toute la collection de requêtes prête à tester.
